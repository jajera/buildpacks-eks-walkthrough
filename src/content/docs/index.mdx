## Why this lab

Most <Tooltip term="eks" label="EKS" /> platforms already have <Tooltip term="gitops" label="GitOps" /> for **deploy**. The gap is **build**: Dockerfiles in
every repo, CI secrets for ECR, and base-image upgrades chased per service.

<Tooltip term="buildpacks" label="Cloud Native Buildpacks" /> centralize that on the platform —
one builder, patched stacks, consistent images. <Tooltip term="kpack" label="kpack" /> runs builds
on-cluster; <Tooltip term="codecommit" label="CodeCommit" /> and managed
<Tooltip term="argocd-capability" label="Argo CD" /> keep the loop on AWS without GitHub for the
pipeline.

End to end: push Go source to CodeCommit → kpack builds with buildpacks → image in
<Tooltip term="ecr" label="ECR" /> → Argo CD deploys →
<Tooltip term="pulse" label="Pulse" /> in the browser. No Dockerfile in the app repo.
